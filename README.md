# 🚨 ResQ — Intelligent Emergency Routing System

> ⚡ *We don’t just place emergency calls — we ensure they succeed.*

---

## 🧠 Overview

**ResQ** is a smart emergency response system that intelligently routes SOS requests to the **best available emergency center** in real-time.

Unlike traditional systems that fail when a call is busy or dropped, **ResQ detects failures and reroutes automatically** — ensuring help always reaches the user.

---

## 🚀 Key Features

✨ **Smart SOS Trigger**

* One-click emergency activation
* Supports Mobile & VoIP calls

📍 **Real-time Location Detection**

* GPS / Network-based tracking
* Accurate caller positioning

🧠 **AI Decision Engine**

* Selects best center using:

  * Distance
  * Availability
  * Network reliability

🔁 **Auto Rerouting System**

* Detects failures (busy, dropped, no response)
* Instantly connects to next best center

📡 **Fallback Communication**

* Ensures response even if calls fail
* Future-ready: SMS / Internet-based alerts

📊 **Live Admin Dashboard**

* Monitor calls, centers, and routing attempts
* Simulate failures & congestion

---

## ⚙️ How It Works

```
User presses SOS
        ↓
Location is detected
        ↓
Best center is selected
        ↓
Call is initiated
        ↓
If failed → Reroute
        ↓
If all fail → Fallback triggered
```
